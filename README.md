# スマラダー 公開ページと公開データ

[スマラダー](https://smaladder.com)は『大乱闘スマッシュブラザーズ SPECIAL』の1on1レート戦を行う、非公式・個人運営のサービスです。任天堂株式会社とは関係ありません。

このリポジトリは https://smaladder.com の中身そのものです。ボットが毎日自動で書き出して commit します。

- `csv/`：全対戦の結果、ランキング、プレイヤー一覧、シーズン一覧、各シーズンの最終順位（列の説明は [公開データ](https://smaladder.com/data.html)）
- `spec.html`：[公開仕様書](https://smaladder.com/spec.html)（レートの計算式など）
- 毎日の変更は commit の履歴として残ります。過去のデータが後から書き換えられていないことは、履歴で確かめられます。
- 運営者が対応できなくなっても、このリポジトリを複製すればその日までのデータが手元に残ります。

公開データの利用条件（ライセンス）はまだ決めていません。決まったらここに書きます。
